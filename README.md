# Streaks Banner Generator

Single-file tool for generating Streaks.vip's banners: the 3:4 game card, the main top banner, and the inner banner. No build step, no install — open `index.html` in any browser.

## Use

- Double-click `index.html` to open it locally, or
- Enable GitHub Pages on this repo (Settings → Pages → deploy from `main`) for a shareable link.

`banner-default.png` must stay in the same folder as `index.html`.
